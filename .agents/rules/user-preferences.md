# 使用者偏好與行為準則 (User Preferences & Strict Rules)

1. **嚴格保護原有架構與內容**：
   - 絕對不可在更新特定資料或功能時，重寫、覆蓋、刪除或破壞原有未要求修改的程式碼、頁面架構、HTML 元素與 CSS 樣式。
   - 任何改動必須維持精準作用範圍（Surgical Edits），僅針對請求更新的特定資料點或元件進行微調。

2. **數據追蹤範圍與風格**：
   - 主體視覺維持「高質感日系清新風格 (Japanese Light & Fresh)」。
   - 數據觀測聚焦於 4 大指標：新聞稿數量、媒體報導篇數、社群網路聲量、KOL 實況主合作數。
