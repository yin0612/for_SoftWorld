# 中國遊戲版號與審批監測更新

新增遊戲產業頁「中國遊戲版號與審批」分類、文章徽章、範圍計數與摘要統計。沿用既有版面與新聞資料欄位。

新增 `industry-cn-game-approval`：版號／遊戲審批 AND 遊戲、具名廠商或作品語境，繁簡皆維護。補上國際競業的米哈遊及部分簡體公司別名。電影或圖書版號、一般 ISBN、遊戲版本號、軍事坦克、普通 IPO 及無版號語境的遊戲促銷不會命中新分類。

新增 IT之家官方 RSS，以及 IT之家、遊戲陀螺、遊民星空、國家新聞出版署的指定網域 Google News 來源；原有中港媒體加上版號專項查詢。版號專項使用簡體中文 Google News 索引，其他既有查詢保留原設定。所有結果仍須通過來源網域、日期及分類檢查，保留原文跳轉連結，聚合來源不標為官方 RSS。

2026-10-06 已使用新查詢補抓近兩個月新聞，取得 120 則新分類內容，包含 9/30 米哈遊《源初之結》版號報導。增量補抓保留前一完整快照的生成時間，各新文章記錄自己的 `fetched_at`，避免讓其他資料誤顯為剛更新。

國家新聞出版署的聚合查詢當次可讀但無結果，官方公告欄目仍以直接連結供查核。未把「Google 無結果」解讀為官方沒有公告，也未把政府 HTML 宣稱為 RSS。

資料庫透過 `0007_cn_game_approval.sql` 增量加入來源、規則與媒體目錄，保留既有文章與來源健康紀錄。

驗證：15 項 Python 測試、31 項 Node 測試通過；涵蓋實際報導標題、繁簡條件、非遊戲誤報、Google 出版者網域、IT之家官方 RSS 與台灣 iThome 的網域區別、前端分類。Worker 部署預檢通過。
