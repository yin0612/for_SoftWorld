# 遊戲監測v2（2026-11-09）

遊戲頁沿用金融科技頁面的摘要、分類、來源／搜尋、卡片及載入更多，保留原五類與近兩個月時間窗口；增加各類子主題、共用事件及可展開的市場／平台／內容性質條件。預設全部遊戲產業、發布時間由新到舊，不設近7日重點。

`js/gaming.js`提供純資料分類、產品別名、精準遊戲規則和同日同標題報導整理；不推算排名、營收或代理關係。市場及平台顯示為「文中提及」，並不直接當成發行地區或產品實際平台。完整服務名稱與遊戲名稱分開，RAGLAND、PlayZone不自動視為手機新作；新遊不自動列入高營收名單。

新增10條規則涵蓋市場新遊、產品、公司事件、IP商標、商店政策、即玩、雲端、UGC、分潤及商業營運。原有平台規則撤下玩家／會員／類型等寬詞，公司規則將人人、傳奇改成正式品牌；索引標題不視為單篇新聞。所有規則維持兩個必要OR群組以內，RSS摘要與Google標題分開驗證。

## 更新方式

1. 修改共享規則後執行`node scripts/generate_gaming_rules.mjs`，同步JSON、Worker版本與冪等遷移`0011_gaming_v2.sql`。
2. 在既有D1套用遷移，再發布Worker。
3. `node scripts/reclassify_gaming.mjs`明確重分類RSS／聚合快照，保留來源及更新紀錄，不依賴讀取時的舊規則再驗證來新增標籤。
4. D1歷史補收：匯出資料窗口內approved文章後，以`node scripts/reclassify_gaming.mjs <匯出JSON> <輸出SQL>`產生新增命中。SQL只對仍approved文章寫入、衝突時不覆蓋任何既有人工審查。文章與歷史紀錄不刪除。
5. `python scripts/update_gaming_aggregated.py`執行50組遊戲專用查詢，合併既有資料；單獨記錄gaming_refresh時間，不冒充全部金融科技來源都已刷新。既有完整聚合排程會接續使用新增查詢。

來源沿用核准網域，增加GNN、4Gamers與遊戲基地的Google News遊戲專題來源，清楚區分RSS與聚合。韓日原始來源仍須獨立驗證，不把候選來源標成已接入；目前海外事件可由核准台灣／中國媒體報導收錄。

## 驗證

- Node回歸測試涵蓋13個需求情境、未知新遊、費率政策、索引／普通詞反例、未來上市與測試狀態、來源差異及同題相關報導。
- Python測試涵蓋專用查詢的明確啟用與標題分類，保留既有來源、日期及付款類測試。
- 本機與正式頁檢查原五類、子主題、搜尋、進階條件與清除操作；正式頁另確認新規則結果及實際資料時間。

資料缺口仍按原文可得資訊處理：只有標題者不補寫詳細角色、費率及排行榜；使用者需求案例的測試通過不代表每一則外部新聞都已完整查獲。
