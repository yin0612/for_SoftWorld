# 金融科技與穩定幣監測企畫書

## 目標

建立一個可獨立使用的金融科技與穩定幣新聞頁面，將台灣支付、國際金融科技、穩定幣與鏈上結算新聞集中呈現。所有公開結果都必須來自已驗證 RSS、保留原文連結與規則命中證據，並限制在台北時間近兩個月的資料窗口。

## 規格來源與分析

本方案比對了金融科技&穩定幣監測資料夾中的關鍵字清單.xlsx 與監測關鍵字及媒體.docx。

- 藍新科技台灣與中港澳欄位含 23 個精準支付品牌詞。全盈+PAY 是品牌名稱，不應因加號被拆成兩個群組條件。
- 台灣支付的原始情境規則由 9 個主題詞與 101 個支付、金融、風險或數位資產詞交叉組成；本版再加入「台灣支付核心新聞」與「主管機關／支付基礎建設」兩條高精準規則，限定台灣 RSS 來源並補足「電支、非現金支付、支付安全、聯卡中心、信用卡、TWQR」等台灣新聞常用寫法。
- 文件列出 90 家台灣候選媒體與 22 家不重複的國際金融科技或加密資產候選媒體。本版已驗證並啟用 18 個台灣 RSS 管道（含中央社產經／科技、聯卡中心三個支付頻道、卡優、自由、科技報橘、動區動趨與 ABMedia）與 11 個國際 RSS 管道；其他媒體維持候選狀態，必須完成 RSS、授權與健康檢查後才能自動收錄。
- 原始文件有虛擬貨幣、加密貨幣與區塊鏈等情境詞，但沒有穩定幣專屬詞。這些廣義詞不能直接代表穩定幣新聞，否則會混入一般加密資產或遊戲區塊鏈報導；本次新增奧丁丁／OwlPay 優先規則，但要求同時出現穩定幣、鏈上支付、加密資產或金融科技語境。

## 網頁方案

新分頁使用 #/fintech 路由，預設進入「台灣支付（優先）」視圖，另提供全部金融科技、國際金融科技、穩定幣與鏈上結算三種視圖。頁面會顯示台灣支付篇數、全部篇數、穩定幣篇數、台灣 RSS 來源數、已驗證來源數與資料日期範圍，並支援來源與文字篩選、載入更多，以及每篇文章的規則命中詞和原文連結。

穩定幣視圖會辨識已驗證 RSS 摘要中出現的高精準穩定幣詞，讓既有已收錄文章能立即呈現；奧丁丁／OwlPay 命中穩定幣規則時會顯示優先徽章並置頂。新規則則由 Cloudflare Worker 的每小時收集排程持續寫入資料庫；在規則 seed 尚未完成時，台灣專業 RSS 也提供唯讀即時補位。

## 資料品質與營運

- 僅保存 RSS 提供的標題、摘要、日期、原文 URL 與命中證據，不鏡像未授權全文。
- 公開 API 只回傳 approved 文章與 approved 規則命中，不使用展示資料替代。
- 台北時間近兩個月是收錄與公開查詢的共同窗口。
- 收集排程每小時第 17 分鐘執行一次。來源錯誤、授權不明或未驗證 RSS 不會自動進入公開頁。
- 公開 API 對新增台灣來源提供唯讀即時補位；每篇仍保留 RSS 來源與原文 URL，並以 URL 與 D1 結果去重，避免等待排程或資料庫 seed 時國內新聞空窗。
- 新增的台灣官方／專業 RSS 會保留原文連結與來源標示；中央社 RSS 僅保存標題、前言與文章連結，並遵守其使用規範。未來若加入新媒體，必須先驗證 RSS 可用性、內容更新頻率、授權條件與來源健康狀態。
